# @log-company/plugin-chats

CRM-чаты Log Company для NocoBase 2.0.60: личные и групповые беседы, управление участниками, курсорная история, непрочитанные чаты, мягкое удаление сообщений и вложения в MinIO.

## Основные свойства

- один личный чат на неупорядоченную пару пользователей;
- группы с ролями `owner`, `admin`, `member`;
- проверка активного membership на сервере для каждого действия;
- текстовые, системные и файловые сообщения;
- до 10 вложений по 25 МБ с проверкой расширения, MIME и фактического содержимого;
- polling раз в 12 секунд и badge количества непрочитанных чатов;
- snapshot имени участника и автора при удалении пользователя;
- независимость от `plugin-process-discussion` и таблицы `process_comments`.

Полное устройство, конфигурация и команды проверки описаны в [документации](../../../../docs/log-company/CHATS_PLUGIN.md).
