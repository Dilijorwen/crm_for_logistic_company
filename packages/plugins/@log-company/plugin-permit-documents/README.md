# @log-company/plugin-permit-documents

Коллекция разрешительных документов для NocoBase 2.0.60. Каждый документ относится к одной записи
`our_companies`; компания может иметь несколько разрешительных документов. Вложения хранятся стандартным файловым
менеджером NocoBase.

Подробное описание модели и проверки приведены в
[документации](../../../../docs/log-company/PERMIT_DOCUMENTS_PLUGIN.md).
