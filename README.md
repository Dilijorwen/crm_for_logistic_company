# CRM для логистической компании

Проект представляет собой CRM-систему для логистической компании, разработанную на основе открытой no-code/low-code
платформы [NocoBase](https://github.com/nocobase/nocobase).

В качестве технологической основы использован официальный исходный репозиторий:
[github.com/nocobase/nocobase](https://github.com/nocobase/nocobase).

Специализированная функциональность CRM реализована в собственных плагинах Log Company, расположенных в
`packages/plugins/@log-company/`. Они расширяют базовую платформу средствами для работы с логистическими процессами,
документами, обсуждениями, организационной структурой, чатами и поиском.

Инструкция по публикации проекта на виртуальной машине и последующим обновлениям через SSH находится в
[deploy/README.md](deploy/README.md).
